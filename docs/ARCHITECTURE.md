# 韵界电商平台 - 系统架构说明文档

## 1. 系统概述

韵界电商平台（云洁小程序）是一个基于微服务架构的全栈电商解决方案，包含后端 API 服务、前端小程序和管理后台三大核心模块。

## 4. 模块架构

### 4.1 后端模块划分

```
nestapi/src/modules/
├── auth/                 # 认证模块 - JWT 登录、注册、权限验证
├── users/                # 用户模块 - 用户信息管理
├── admin-users/          # 管理员模块 - 后台用户管理
├── products/             # 商品模块 - 商品 CRUD、库存管理
├── categories/           # 分类模块 - 商品分类管理
├── collections/          # 集合模块 - 商品集合管理
├── array-collections/    # 数组集合 - 多商品组合
├── orders/               # 订单模块 - 订单生命周期管理
├── cart/                 # 购物车模块 - 购物车操作

├── addresses/            # 地址模块 - 收货地址管理
```

## 9. 安全架构

### 9.1 安全措施

| 层级 | 安全措施 |
|------|----------|
| 传输层 | HTTPS/TLS 加密 |
| 认证层 | JWT Token + 过期机制 |
| 密码存储 | bcrypt 哈希加密 |
| API 层 | 请求验证 + 参数校验 |
| 数据层 | TypeORM 防 SQL 注入 |

## 10. 扩展性设计

### 10.1 水平扩展

- **无状态服务**: API 服务无状态，可水平扩展
- **数据库读写分离**: 支持主从复制
- **CDN 加速**: 静态资源通过 COS CDN 分发

### 10.2 模块化设计

- **松耦合**: 各模块独立，通过接口通信
- **可插拔**: 新功能可作为独立模块添加
- **配置化**: 核心参数通过环境变量配置
