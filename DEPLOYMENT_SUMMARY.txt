6. HOW TO DEPLOY NEW CODE
================================================================================

STEP 1: Build on local machine
  $ npm run build
  → Creates dist/ folder with compiled code

STEP 2: Upload to server
  $ rsync -avz dist/ root@123.207.14.67:/opt/ruizhu-app/nestapi-dist/dist/

STEP 3: On server, backup current version
  $ ssh root@123.207.14.67
  $ cd /opt/ruizhu-app
  $ cp -r nestapi-dist nestapi-dist-backup-$(date +%Y%m%d)

STEP 4: Restart PM2
  $ pm2 restart ruizhu-backend

STEP 5: Verify deployment
  $ pm2 logs ruizhu-backend
  $ curl http://localhost:8888/health

If something goes wrong, rollback:
  $ pm2 stop ruizhu-backend
  $ cp -r nestapi-dist-backup-YYYYMMDD nestapi-dist
  $ pm2 start ruizhu-backend

  1. Check PM2 status: pm2 list
  2. Check logs: pm2 logs ruizhu-backend --err
  3. Check database connection in logs
  4. Restart: pm2 restart ruizhu-backend
  5. Check port: lsof -i :8888

  1. Check Nginx status: systemctl status nginx
  2. Check error log: tail -f /var/log/nginx/ruizhu-error.log
  3. Verify files exist: ls -la /opt/ruizhu-app/admin/
  4. Test Nginx config: nginx -t
  5. Reload Nginx: nginx -s reload

  1. Test directly: mysql -h gz-cdb-qtjza6az.sql.tencentcdb.com -P 27226 -u root -p
